CO₂ Capture Digital Twin for Urban Emissions Monitoring and Planning

This project implements a CO₂ Capture Digital Twin for an urban environment (Pune) enabling real-time visualization, analysis, and scenario-based planning of carbon emissions.

Built using Streamlit and Leaflet/Folium, the system integrates multi-source emissions including vehicular traffic, industry, energy, and waste management.

Core Features

  • Spatial point layers and aggregated heatmaps
  • Grid-based CO₂ intensity visualization
  • Real-time heatmap parameter tuning
  • Layer toggles for emission sources
  • Simulation-ready intervention framework

The architecture cleanly separates data processing (Python), visualization (Streamlit), and map rendering (Leaflet), making it scalable and production-ready.

🏙️ Sahaay – Crowdsourced Civic Issue Reporting Platform

Sahaay is a web-based platform enabling citizens to report civic issues such as potholes, broken streetlights, and waste problems while allowing municipal authorities to manage and resolve them efficiently.

Key Features

  • 📍 Geo-tagged issue reports
  • 📸 Photo uploads
  • 📝 Descriptive issue notes
  • 📊 Interactive admin dashboard
  • 🔔 Real-time status updates
  • 🗂️ Department-based routing

Tech Stack

  • Backend: PHP
  • Database: Amazon RDS (MySQL / PostgreSQL)
  • Hosting: AWS EC2
  • Storage: Amazon S3 (planned)
  • Monitoring: Amazon CloudWatch
  • Frontend: HTML / CSS / JS
